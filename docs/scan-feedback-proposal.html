03

สรุปพฤติกรรมแต่ละผล

ผลเกิดเมื่อสีสั่น / เสียงไปต่อ
สำเร็จบันทึกส่ง/ตัดสต๊อกได้จริงเขียวสั่นสั้น 1 · ติ๊งสูงอัตโนมัติ ~1 วิ
ซ้ำกล่องนี้เคยสแกนแล้วเหลืองสั่น 2 จังหวะ · ตุ๊บอัตโนมัติ ~1.5 วิ (ไม่นับเพิ่ม)
ไม่สำเร็จไม่พบออเดอร์ · ยังไม่ตัดสต๊อก · เน็ตล่มแดงสั่นยาว 3 จังหวะ · เสียงเตือนต่ำต้องกด "รับทราบ" (บังคับหยุด)
04

ใช้กับหน้าไหน

🚚 จัดส่งสินค้า /ship

สแกนต่อเนื่องทีละกล่อง — ได้ประโยชน์เต็มที่ ต้องรู้ทันทีว่ากล่องไหนบันทึกส่งได้ กล่องไหนซ้ำ/ยังไม่ตัดสต๊อก แล้วแยกไว้

📦 ตัดสต๊อก / SKU /stock/issue

สแกนทีละครั้ง — ขึ้นผลสั้นๆ (พบใบ/ไม่พบ) แล้วปิดกล้องเข้าหน้าตรวจรายการ · ถ้าไม่พบ ค้างผลให้ลองใหม่ ไม่เด้งปิดเงียบ

05

ทำจริงยังไง (สั้นๆ)

แก้เฉพาะ CameraScan + วิธีที่หน้าเรียกใช้ ไม่แตะฐานข้อมูล

เปลี่ยน onScan ให้คืน "ผล" กลับมาให้กล้องรู้

// เดิม: ยิงแล้วจบ ไม่รู้ผล
onScan: (code) => void

// ใหม่: หน้าเจ้าของประมวลผลแล้วคืนผลให้กล้องโชว์
onScan: (code) => Promise<{
  status: "ok" | "dup" | "error",
  title: string,       // "บันทึกส่งแล้ว" / "สแกนซ้ำ" / "ไม่พบออเดอร์"
  detail?: string      // "กล่องที่ 13 · Dionysus X"
}>
  • กล้อง เข้าสถานะ checking ทันทีที่อ่านได้ → หยุดรับโค้ดใหม่ → รอ await onScan()
  • ได้ผลมาแล้วโชว์ overlay ✓/⚠/✗ + สั่น/เสียงตามผล · ok/dup ตั้งเวลาปิดเอง · error รอกดปุ่ม
  • ตัวนับเปลี่ยนจาก "จำนวนอ่านดิบ" → แยกตามผลจริง (✓ / ⚠ / ✗)
  • เพิ่มเสียง (Web Audio beep) — ทำงานได้แม้ปิดเสียงสั่น เหมาะกับที่เสียงดัง
  • ใช้ซ้ำได้ทั้ง 2 หน้า — จัดส่ง (continuous) กับ ตัดสต๊อก (ทีละครั้ง)
